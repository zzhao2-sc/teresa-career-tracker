EVIDENCE ROADMAP

八个阶段，每一步都有验收门

不要按日硬赶。每阶段预计 1–2 周，完成验收后再继续。项目可以慢，但不能用“看起来完成”替代可运行、可解释的证据。

00 · SCOPE1 周 · 3h

问题与安全边界

先确定一个 Teresa 熟悉的护理工作流。

Gate 0Teresa 不看稿也能讲清用户、风险及为何不做诊断。
01 · GOLD SET2 周 · 6–8h

案例与评分标准

这是最不能外包给 AI 的差异化资产。

Gate 1数据与 rubric 已版本化；Teresa 能解释 3 个边界案例。
02 · BASELINE2 周 · 6h

可复现评估器

先跑通一个模型、prompt 和指标。

Gate 2按 README 一条命令可运行，配置和失败分类可追溯。
03 · HUMAN REVIEW1 周 · 4h

护士复核闭环

争议结果交给人，不让 AI 自行作临床决定。

Gate 3有 audit trail、5 个失败案例和 limitations。
04 · HEALTH DATA2 周 · 7h

FHIR、API 与 SQL

对齐医疗产品和 Clinical Informatics 岗位。

Gate 4API 有文档、SQL 可重跑、FHIR 映射有 provenance 和测试。
05 · SCALE2 周 · 6h

升级为评估平台

Scale 是批量、可重跑、可追踪，不是盲目生成海量案例。

Gate 5基线与改进可重跑，简历数字可再生。
06 · PUBLIC DEMO1–2 周 · 5h

招聘经理十分钟看懂

公开演示只用合成数据。

Gate 6URL、GitHub、report、视频可访问；无 PHI 或夸大声明。
07 · CAREER EVIDENCE1 周 · 4h

变成求职证据

达到可复现后才能在简历写 built/evaluated。

Final GateTeresa 能无辅助解释并修改核心代码。

AI COLLABORATION CONTRACT

大量用 AI，但不把理解外包

标准不是代码是否由 AI 起草，而是 Teresa 是否做了关键决定、审核结果、能解释风险，并能独立修改。

GREEN · 放心交给 AI

机械成本

  • 目录、样板、配置草稿
  • README、API 文档和文字润色
  • 测试草稿和边界提醒
  • 重构、类型和 lint
  • 合成案例草稿，由 RN 审核
  • 部署说明和页面样式
YELLOW · AI 结对，Teresa 过手

核心工程

  • Python、FHIR、FastAPI
  • SQL 和数据库 schema
  • 指标、重试和日志
  • 模型调用与测试
  • Teresa 要运行、debug、改写、解释
  • 保留 prompt 和 review notes
RED · 不交给 AI 决定

临床责任

  • rubric 和 ground truth
  • Critical 错误定义
  • 人工 adjudication 与结论
  • 隐私、边界和上线门槛
  • 简历贡献和量化指标
  • 面试回答与现场修改

Teresa 必须拥有

临床定义、rubric、人工复核、指标解释，以及至少一条端到端 Python/SQL 路径。

你可以负责

环境、GitHub、部署、视觉、任务拆分、code review 和重复工作。

AI 的角色

Pair programmer、reviewer、文档助手；不能充当临床责任人或制造履历。

面试表达：“I used AI coding tools for scaffolding and review. I personally defined the clinical rubric, validated every scenario, implemented and debugged the core evaluation path, and can explain the design decisions and failure cases.”

RECRUITER EXPERIENCE

不是只发布一个 ChatGPT

Custom GPT 不能证明数据、评估、测试和后端工程；最多作为入口。

01PRIMARY

公开 GitHub Repository

代码、README、架构、data provenance、测试、复现命令、实验和 Teresa 的 commits。

02LIVE PRODUCT

简单在线 Demo

展示合成场景、模型输出、RN review、failure type 和版本比较。

03TECHNICAL PROOF

Evaluation Report

方法、指标、baseline、改进、失败、限制；所有数字可重跑。

04COMMUNICATION

三分钟 Demo Video

Teresa 本人讲问题、数据流、失败案例及指标意义。

05OPTIONAL

Custom GPT / Chat UI

可作入口，但必须链接 GitHub 和报告，不能冒充工程证据。
